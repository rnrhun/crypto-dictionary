# crypto-dictionary
Master the language of blockchain with 150 must-know terms. An easy-to-read, beginner-friendly dictionary that removes the barrier to entry for cryptocurrency, helping newcomers understand the market with confidence.

## 모아쓰기 — 훈민정음 낙하 퍼즐

`game/index.html`을 브라우저로 열면 바로 할 수 있습니다. 빌드가 없습니다.

떨어지는 자모를 모아 쓰면 글자가 되고, 글자가 모이면 낱말이 되어 사라집니다.

- 모음이 자음 위에 앉으면 한 글자로 합쳐집니다. ㄱ 위에 ㅏ가 오면 가.
- 자음이 완성된 글자 위에 앉으면 받침이 됩니다. 가 위에 ㄱ이 오면 각. 겹받침과 겹모음도 됩니다.
- 완성 글자로 꽉 찬 줄은 사라집니다. 사전에 있는 낱말이 가로(왼쪽에서 오른쪽)나 세로(위에서 아래)로 이어져도 사라집니다.
- 이번 낱말로 뜬 암호화폐 용어를 지으면 세 곱을 받고, 뜻풀이가 뜹니다.

낱말과 뜻풀이는 `game/dictionary.js`에 있습니다. `crypto`에 용어를 더하면 목표 낱말로 나오고, `common`에 더하면 우연히 이어졌을 때 덤으로 사라집니다.
